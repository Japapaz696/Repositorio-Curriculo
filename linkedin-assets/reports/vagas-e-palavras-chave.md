## Pesquisas reutilizáveis

Usar os títulos como termos de busca e conferir sempre a página da empresa:

- Desenvolvimento: `desenvolvedor Node júnior`, `desenvolvedor JavaScript júnior`, `desenvolvedor React júnior`, `desenvolvedor Angular júnior`, `desenvolvedor SQL Server júnior`.
- Experiência transferível: `analista suporte software júnior`, `analista suporte ERP SQL`, `helpdesk júnior`, `suporte N1`, `analista implantação júnior`, `customer onboarding júnior`.
- Transição condicionada: `customer success júnior suporte`, `estágio automação`, `estágio inteligência artificial`, `analista dados júnior SQL`.

Antes de adaptar uma candidatura, conferir inscrição, localização/modelo de trabalho, idioma, formação/matrícula e requisitos obrigatórios. Usar apenas termos que correspondam a fatos, conhecimentos ou projetos explicáveis em entrevista.
