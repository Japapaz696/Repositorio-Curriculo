# Site profissional — Verônica Reis Santana

**Categoria:** Projeto web para apresentação profissional.

**Texto pronto para LinkedIn:**

Construí um site institucional para a psicóloga Verônica Reis Santana, com apresentação profissional, especialidades, certificados, depoimentos, blog e interface de agendamento. Desenvolvi páginas responsivas em HTML, CSS e JavaScript e uma API Node.js/Express com armazenamento em JSON. A demonstração está publicada no Render; a administração segue em evolução.

**Problema / objetivo:** Organizar informações profissionais e facilitar o acesso às especialidades e ao contato/agendamento.

**O que desenvolvi:** Páginas institucionais, identidade visual, navegação, formulários e API de agendamentos.

**Tecnologias reais:** HTML5, CSS3, JavaScript, Node.js, Express e armazenamento em arquivo JSON. Publicação no Render.

**Funcionalidades:**

- Páginas de apresentação, especialidades, certificados, depoimentos e blog
- Layout responsivo e navegação
- Interface de agendamento
- Rotas de API para agendamentos no código

**Aprendizado / destaque:** Estruturação de conteúdo, integração front-end/backend e distinção entre interface publicada e operação segura de dados.

**Resultado verificado:** Home pública aberta em desktop/mobile. O formulário público retornou HTTP 503 em uma verificação adicional; a captura do formulário foi feita localmente.

**Limites:** Não foi validado agendamento completo. A sessão do painel e o acesso a dados precisam de revisão. Não afirmar banco SQL, impacto comercial, conformidade de privacidade ou administração pronta para produção.
