# Lucas Dev — apresentação de soluções digitais

**Categoria:** Projeto próprio · Landing page demonstrativa.

**Texto pronto para LinkedIn:**

Desenvolvi uma landing page para apresentar serviços e conceitos de soluções digitais. A interface inclui seções de serviços, configurador de estimativa de orçamento e geração de mensagem para contato pelo WhatsApp. Projeto front-end em HTML, CSS e JavaScript, publicado como demonstração.

**Problema / objetivo:** Explorar uma apresentação de serviços digitais e um fluxo de escolha de recursos para estimativa de orçamento.

**O que desenvolvi:** Landing page, estilos responsivos, interações e cálculo de estimativa no navegador.

**Tecnologias reais:** HTML5, CSS3 e JavaScript.

**Funcionalidades:**

- Seções de serviços e projetos
- Configurador de orçamento
- Estimativas calculadas no navegador
- Montagem de mensagem e abertura de WhatsApp

**Aprendizado / destaque:** Comportamentos de formulário, estado de interface e comunicação de opções de um serviço.

**Resultado verificado:** Demo pública localizada e verificada por HTTP; home e configurador capturados localmente. README local atualizado com o link.

**Limites:** O catálogo cita possibilidades de integrações; isso não prova implementação de banco, automações ou agentes. Não apresentar como empresa com carteira de clientes ou faturamento.
