# Portfolio Anna — site pessoal

**Categoria:** Projeto web · Interface e identidade visual.

**Texto pronto para LinkedIn:**

Criei um site pessoal com identidade visual própria para Anna Clara, organizado em páginas de apresentação, formação e trajetória acadêmica. Desenvolvi layout responsivo, navegação mobile, animações de entrada e galeria com lightbox usando HTML, CSS e JavaScript. O projeto está disponível no GitHub Pages.

**Problema / objetivo:** Apresentar a trajetória de Anna Clara em um site pessoal com organização e identidade visual próprias.

**O que desenvolvi:** Páginas de apresentação, sobre, formação, curiosidades e vida acadêmica, com estilos e interações em JavaScript.

**Tecnologias reais:** HTML5, CSS3, JavaScript e GitHub Pages.

**Funcionalidades:**

- Site multipágina e layout responsivo
- Menu mobile
- Animações de entrada e galeria com lightbox
- Tratamento de movimento reduzido em interações específicas

**Aprendizado / destaque:** Consistência entre páginas, navegação e escolhas visuais adaptadas à pessoa apresentada.

**Resultado verificado:** Demonstração pública aberta em desktop e mobile. README local atualizado com a URL real.

**Limites:** Recursos de acessibilidade encontrados no código não equivalem a auditoria integral WCAG.
