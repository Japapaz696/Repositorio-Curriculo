# Portfólio — Lucas Santana da Paz

Portfólio pessoal de Lucas Santana da Paz, estudante de Análise e Desenvolvimento de Sistemas. Apresenta projetos de desenvolvimento web, sistemas, suporte, SQL e automação.

**Demonstração:** [japapaz696.github.io/Repositorio-Curriculo](https://japapaz696.github.io/Repositorio-Curriculo/)

## Sobre o projeto

Site estático feito com HTML, CSS e JavaScript, sem framework ou etapa de build, pronto para publicação no GitHub Pages.

## Seções

- **Experiência:** atuação com suporte ERP e diagnóstico de sistemas.
- **Projetos:** OmniOps AI, SupportFlow, Sistema Verônica, Seu Manoel, Beauty Store, Papitos, SQL Lab e barbearia, com links para demonstrações ou repositórios.
- **Certificações & Credenciais:** três certificados freeCodeCamp, com imagens, links oficiais e resumo dos conteúdos e projetos das trilhas.
- **Técnica aplicada a entrega:** tecnologias e práticas usadas nos projetos.
- **Perfil e processo:** formação, foco profissional e etapas de planejamento, estudo, estruturação, desenvolvimento, validação e entrega.
- **Contato:** links e formulário.

## Tecnologias

HTML5 semântico, CSS3, JavaScript, Git e GitHub Pages. Os projetos também usam tecnologias como Node.js, Express, PostgreSQL, React, TypeScript e Vite.

## Acessibilidade e desempenho

O site inclui link para pular ao conteúdo, navegação por teclado, textos alternativos nas imagens e carregamento preguiçoso para imagens de projetos. As páginas são estáticas e não exigem instalação de dependências.

## Como executar

Abra `index.html` no navegador ou inicie um servidor estático na pasta do projeto:

```bash
python -m http.server 8000
```

## Estrutura

- `index.html`, `style.css` e `script.js` — portfólio principal;
- `projetos/` — demonstrações independentes;
- `assets/` — recursos visuais;
- `tests/` — testes automatizados dos projetos.
